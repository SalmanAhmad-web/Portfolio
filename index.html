About Me

I build the whole product, not just one layer.

I'm Salman Ahmad, a full-stack web developer from Bahawalpur, Pakistan. I build production-ready applications on the MERN stack (MongoDB, Express, React and Node.js), and I design and develop custom Shopify themes with Liquid, plus full-stack Shopify apps: Node.js backends wired into the Admin API with a Polaris-based UI.
